## 🔴 부정경쟁방지 및 영업비밀보호에 관한 법률 ★★★

### 문제 (2024년 기출)
```
부정경쟁방지법에서 보호하는 영업비밀의 요건은?
```

### ✅ 정답
```
부정경쟁방지 및 영업비밀보호에 관한 법률
(약칭: 부정경쟁방지법)

목적:
영업비밀 보호, 부정경쟁행위 방지

영업비밀의 요건 (3가지) ★★★:

1. 비밀성 (Secret) ★★★
   - 공개되지 않은 정보
   - 불특정 다수에게 알려지지 않음

2. 경제성 (Economic Value) ★★★
   - 독립적인 경제적 가치
   - 경쟁 우위 제공

3. 비밀관리성 (Reasonable Efforts) ★★★
   - 상당한 노력으로 비밀 유지
   - 보안 조치 (접근 통제, 비밀유지계약 등)

예시:
- 고객 명단
- 제조 공정
- 원가 정보
- 소스 코드 ★
- 영업 전략

비밀관리성 인정 요소:
- 물리적 보안 (출입 통제)
- 기술적 보안 (암호화, 접근 통제)
- 비밀유지계약 (NDA) ★★
- 비밀표시 (대외비, Confidential)
- 교육 및 훈련

부정경쟁행위:

1. 부정취득 ★★★
   - 절도, 사기, 협박
   - 해킹 ★★
   - 부정 접근

2. 부정사용/공개 ★★
   - 취득한 영업비밀 사용
   - 제3자에게 공개

3. 부정유출
   - 퇴직자가 영업비밀 유출 ★★★
   - 경쟁사로 이직 시

벌칙: ★★★

1. 국외 유출 (해외 공개/사용)
   - 15년 이하 징역
   - 또는 15억원 이하 벌금

2. 국내 침해
   - 10년 이하 징역
   - 또는 5억원 이하 벌금

3. 양벌규정
   - 법인: 30억원 이하 벌금 (국외 유출)
   - 법인: 10억원 이하 벌금 (국내 침해)

민사적 구제:
- 침해 금지 청구
- 손해배상 청구
- 신용회복 조치

vs 특허:
┌──────────┬──────────┬──────────┐
│   구분   │ 영업비밀 │  특허    │
├──────────┼──────────┼──────────┤
│ 등록     │ 불필요 ★│ 필요     │
├──────────┼──────────┼──────────┤
│ 공개     │ 비공개 ★│ 공개     │
├──────────┼──────────┼──────────┤
│ 보호기간 │ 무제한 ★│ 20년     │
├──────────┼──────────┼──────────┤
│ 독점권   │ 없음     │ 있음 ★  │
└──────────┴──────────┴──────────┘

실기 답안:
✅ 비밀성, 경제성, 비밀관리성 (3가지) ★★★
✅ 비밀관리성: 상당한 노력으로 비밀 유지
```

## 🔴 CIA Triad (보안 3요소) ★★★

### 문제 (2024년 기출)
```
정보보호의 3대 목표 (CIA Triad)를 설명하시오.
```

### ✅ 정답
```
CIA Triad = 정보보호 3대 목표

1. 기밀성 (Confidentiality) ★★★

정의:
인가된 사용자만 정보에 접근

위협:
- 도청 (Eavesdropping)
- 스니핑 (Sniffing)
- 사회 공학
- 권한 없는 접근

구현:
- 암호화 (Encryption) ★★★
  · 저장 시: 디스크 암호화 (TDE, FDE)
  · 전송 시: TLS/SSL, VPN
- 접근 통제 (Access Control) ★★★
  · 인증 (Authentication)
  · 인가 (Authorization)
- 물리적 보안
  · 출입 통제, CCTV

2. 무결성 (Integrity) ★★★

정의:
인가된 방법으로만 정보 변경
변조 방지 및 탐지

위협:
- 데이터 변조
- 중간자 공격 (MITM)
- 무단 수정

구현:
- 해시 함수 (Hash) ★★★
  · MD5, SHA-256
  · 파일 무결성 검사
- 디지털 서명 (Digital Signature) ★★★
  · 변조 탐지
  · 부인방지
- 체크섬 (Checksum)
- MAC (Message Authentication Code)
- 버전 관리
- 로그 및 감사

3. 가용성 (Availability) ★★★

정의:
필요할 때 정보/시스템 접근 가능

위협:
- DoS/DDoS 공격 ★★★
- 시스템 장애
- 자연재해
- 랜섬웨어

구현:
- 이중화 (Redundancy) ★★★
  · 서버 이중화 (Active-Standby, Active-Active)
  · 네트워크 이중화
  · 전원 이중화 (UPS)
- 백업 (Backup) ★★★
  · 정기 백업
  · 오프사이트 백업
- 로드 밸런싱 (Load Balancing)
- DDoS 방어
  · Anti-DDoS 서비스
  · CDN
- 재해복구계획 (DRP)
- BCP (Business Continuity Plan)

추가 보안 목표:

4. 부인방지 (Non-repudiation)
   - 행위 부인 불가
   - 디지털 서명 ★★
   - 로그 기록

5. 인증 (Authentication)
   - 신원 확인
   - 비밀번호, OTP, 생체인증

비교:
┌──────────┬──────────────┬──────────────┐
│   목표   │     위협     │     구현     │
├──────────┼──────────────┼──────────────┤
│ 기밀성   │ 도청, 유출   │ 암호화 ★★★ │
├──────────┼──────────────┼──────────────┤
│ 무결성   │ 변조         │ 해시, 서명 ★│
├──────────┼──────────────┼──────────────┤
│ 가용성   │ DoS, 장애    │ 이중화, 백업 │
│          │              │ ★★★        │
└──────────┴──────────────┴──────────────┘

균형 (Tradeoff):
- 암호화 ↑ → 성능 ↓ (가용성 저하 가능)
- 접근 통제 ↑ → 편의성 ↓
- 보안과 사용성의 균형 필요 ★★

실기 답안:
✅ 기밀성: 암호화, 접근 통제
✅ 무결성: 해시, 디지털 서명
✅ 가용성: 이중화, 백업, DDoS 방어 ★★★
```

## 🔴 내부 준법감시인 ★★

### 문제 (2024년 기출)
```
정보통신망법상 내부 준법감시인이란?
```

### ✅ 정답
```
내부 준법감시인 (Compliance Officer)

근거:
정보통신망 이용촉진 및 정보보호 등에 관한 법률
(정보통신망법) 제45조의3

대상: ★★★
정보통신서비스 제공자
- 전년도 매출액 100억원 이상
- 전년도 3개월간 일평균 이용자 100만명 이상

→ ISMS-P 의무 인증 대상과 동일

역할:

1. 법령 준수 점검 ★★
   - 정보통신망법 준수 여부
   - 개인정보보호법 준수 여부

2. 시정 조치 요구
   - 위반 사항 발견 시 시정 요구
   - 대표자에게 보고

3. 교육 및 지도
   - 임직원 대상 법령 교육
   - 컴플라이언스 문화 조성

4. 내부 감사
   - 정기 및 수시 감사
   - 개인정보 처리 실태 점검

자격: ★★

1. 임원 또는 부서장급 이상
2. 전문성 (법률, 정보보호 등)
3. 독립성 확보
   - 다른 업무 겸직 제한

선임 신고:
- 선임 후 14일 이내
- 과학기술정보통신부 또는 KISA에 신고

미선임 시 제재:
- 1천만원 이하 과태료

vs CPO (개인정보보호 책임자):
┌────────────┬──────────────┬──────────────┐
│    구분    │  내부준법감시인│     CPO      │
├────────────┼──────────────┼──────────────┤
│ 근거 법령  │ 정보통신망법 │ 개인정보보호법│
├────────────┼──────────────┼──────────────┤
│ 역할       │ 법령 준수 감시│ 개인정보 보호│
│            │ ★★         │ 총괄 ★★    │
├────────────┼──────────────┼──────────────┤
│ 대상       │ 일부 사업자  │ 모든 개인정보│
│            │ (100억 이상) │ 처리자       │
├────────────┼──────────────┼──────────────┤
│ 신고       │ 필요 ★      │ 불필요       │
└────────────┴──────────────┴──────────────┘

실기 답안:
✅ 법령 준수 감시 및 점검 담당자
✅ 매출 100억원 이상 또는 이용자 100만명 이상
✅ KISA에 선임 신고 필요

## 🔴 내부 통제 (Internal Control) ★★

### 문제 (2024년 기출)
```
정보보호 내부 통제란?
```

### ✅ 정답
```
내부 통제 (Internal Control)

정의:
조직 내부에서 목표 달성을 위해 수립한
정책, 절차, 활동의 체계

목적:

1. 운영의 효율성 및 효과성
2. 재무 보고의 신뢰성
3. 법규 준수 ★★
4. 자산 보호

정보보호 내부 통제 요소:

1. 통제 환경 (Control Environment)
   - 경영진의 의지 ★★★
   - 보안 문화
   - 조직 구조 (CISO, CPO)
   - 권한 및 책임

2. 위험 평가 (Risk Assessment) ★★★
   - 위협 및 취약점 식별
   - 위험도 평가
   - 대응 방안 수립

3. 통제 활동 (Control Activities) ★★★
   - 접근 통제 (Access Control)
   - 직무 분리 (Separation of Duties) ★★
   - 승인 및 검토
   - 물리적 통제
   - 기술적 통제 (암호화, 방화벽)

4. 정보 및 의사소통 (Information & Communication)
   - 보안 정책 전달
   - 보안 인식 교육 ★★
   - 사고 보고 체계

5. 모니터링 (Monitoring) ★★★
   - 로그 모니터링
   - 보안 감사 (Audit)
   - 이상 징후 탐지
   - 정기 점검

직무 분리 (Separation of Duties) ★★★:

원칙:
한 사람이 처음부터 끝까지 수행하지 못하도록 분리

목적:
- 내부 부정 방지
- 오류 방지
- 견제와 균형

예시:

1. 시스템 관리
   - 개발자: 코드 작성
   - 운영자: 배포 및 운영 ★★
   - 감사자: 로그 검토

2. 재무
   - 주문: A 담당자
   - 승인: B 담당자 (관리자)
   - 결제: C 담당자

3. DB 관리
   - DBA: DB 관리
   - 감사자: 로그 분석 ★
   - (DBA가 로그 수정 못하도록)

4. 백업
   - 백업 담당자
   - 복구 담당자 (분리 권장)

최소 권한 원칙 (Principle of Least Privilege) ★★★:

정의:
업무 수행에 필요한 최소한의 권한만 부여

구현:
- 역할 기반 접근 통제 (RBAC) ★★
- 권한 정기 검토
- 불필요한 권한 회수

예시:
- 일반 직원: 읽기 권한만
- 관리자: 쓰기 권한
- 시스템 관리자: 설정 변경

내부 감사 (Internal Audit) ★★★:

목적:
- 통제 활동 효과성 검증
- 법규 준수 확인
- 개선 사항 도출

주기:
- ISMS-P: 연 1회 이상 ★★★
- 수시 감사 (사고 발생 시)

항목:
- 접근 로그 검토
- 권한 적정성 검토
- 보안 정책 준수 여부
- 취약점 점검

실기 답안:
✅ 직무 분리, 최소 권한 원칙 ★★★
✅ 위험 평가, 통제 활동, 모니터링
✅ 연 1회 이상 내부 감사 (ISMS-P)
```

## 🔴 법령 관계 ★★

### 문제 (2024년 기출)
```
정보통신망법, 개인정보보호법, 형사소송법의 관계는?
```

### ✅ 정답
```
주요 정보보호 법령 관계

1. 정보통신망 이용촉진 및 정보보호 등에 관한 법률
   (정보통신망법, 약칭: 망법) ★★★

대상:
정보통신서비스 제공자 (ISP)

주요 내용:
- 개인정보 보호 (정보통신 분야)
- 정보통신망 안정성 확보
- ISMS-P 인증 의무 ★★★
- 침해사고 신고 의무
- 불법 정보 유통 금지

벌칙:
- 개인정보 유출: 5년 이하 징역 또는 5천만원 이하 벌금

2. 개인정보보호법 ★★★

대상:
모든 개인정보 처리자 (공공기관, 민간기업, 개인 등)

주요 내용:
- 개인정보 수집/이용/제공
- 개인정보 안전성 확보 조치
- 개인정보 영향평가 (PIA)
- 개인정보보호 책임자 (CPO) 지정

벌칙:
- 동의 없이 3자 제공: 5년 이하 징역 또는 5천만원 이하 벌금
- 영리/부정 목적: 10년 이하 징역 또는 1억원 이하 벌금

관계:
- 정보통신 분야: 정보통신망법 우선 적용 ★★
- 그 외 분야: 개인정보보호법 적용

3. 형사소송법

관련 조항:
- 제106조: 압수/수색 영장 ★★★
- 제215조: 긴급 압수/수색

디지털 포렌식 관련:
- 적법 절차 (Due Process)
- 영장주의 ★★★
- 증거 수집 절차

4. 전자서명법

주요 내용:
- 공인전자서명 (현재는 '전자서명')
- 공인인증기관 (현재는 '인증기관')
- 전자서명 법적 효력

5. 전자금융거래법

대상:
금융기관, 전자금융업자

주요 내용:
- 전자금융거래 안전성 확보
- 보안성 심의

- 개인신용정보 처리

특별법 > 일반법

전자금융거래법, 신용정보법 (특별법) > 개인정보보호법

실기 답안:

✅ 개인정보보호법: 모든 처리자 대상, 일반법
✅ 형사소송법: 디지털 포렌식 적법 절차, 영장주의 ★★★
