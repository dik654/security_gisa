## 🔴 Linux /etc/passwd 필드 ★★★
```
형식: username:x:UID:GID:GECOS:home:shell

1. username: 사용자명
2. x: 패스워드 (shadow에 저장)
3. UID: 사용자 ID ★★★
   - 0: root
   - 1-999: 시스템 계정
   - 1000+: 일반 사용자
4. GID: 그룹 ID
5. GECOS: 설명
6. home: 홈 디렉토리
7. shell: 로그인 쉘
```

## 🔴 /etc/shadow 보안 강화 ★★★
```
필드: username:password:lastchange:min:max:warn:inactive:expire

보안 강화 방법:
1. max (5번째): 패스워드 최대 사용일
   90 → 패스워드 90일마다 변경 ★★★

2. min (4번째): 최소 사용일
   1 → 즉시 변경 방지

명령어:
chage -M 90 username  # 최대 90일
passwd -n 1 username  # 최소 1일
```

## 🔴 FRR vs FAR ★★★
```
생체인증 오류율

FAR (False Acceptance Rate)
= 타인 수락률 ★★★
비인가자를 인가자로 잘못 인식
보안 위험 ↑

FRR (False Rejection Rate)
= 본인 거부율 ★★
인가자를 비인가자로 잘못 인식
사용자 불편 ↑

CER (Crossover Error Rate)
= 교차 오류율
FAR = FRR인 지점
시스템 성능 지표

ERR (Equal Error Rate)
= CER과 동일
```

## 🔴 Feistel vs SPN ★★★
```
블록 암호 구조

Feistel 구조: ★★★
- DES, 3DES
- 좌우 분할 → 라운드 함수
- 암호화/복호화 구조 동일

SPN (Substitution-Permutation Network): ★★★
- AES
- Substitution (치환) → Permutation (순열)
- 암호화/복호화 구조 다름

매핑:
DES - Feistel ★★★
AES - SPN ★★★
```
