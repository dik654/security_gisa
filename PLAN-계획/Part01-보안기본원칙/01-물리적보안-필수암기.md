# 물리적 보안 - 실기 필수 암기

## 🔴 반입반출 대장 작성 항목 ★★★

### 문제 (2024년 기출)
```
반입반출 대장에 작성해야 하는 항목을 쓰시오.
```

### ✅ 정답
```
1. 반입/반출 일시 (날짜 및 시간)
2. 반입/반출자 성명 및 소속
3. 물품명 및 수량
4. 반입/반출 목적
5. 반입/반출 승인자
6. 물품 일련번호 또는 시리얼 번호 (중요 장비의 경우)
7. 비고 (특이사항)
```

### 📋 반입반출 대장 양식 예시
```
┌──────┬────────┬────────┬────────┬────────┬────────┬────────┐
│ 일시 │ 구분   │ 성명   │ 물품명 │ 수량   │ 승인자 │ 비고   │
├──────┼────────┼────────┼────────┼────────┼────────┼────────┤
│11/05 │ 반출   │홍길동  │노트북  │  1     │김철수  │수리목적│
│14:30 │        │(IT팀)  │(S/N:   │        │(팀장)  │        │
│      │        │        │ABC123) │        │        │        │
├──────┼────────┼────────┼────────┼────────┼────────┼────────┤
│11/06 │ 반입   │홍길동  │노트북  │  1     │김철수  │수리완료│
│09:00 │        │(IT팀)  │        │        │(팀장)  │        │
└──────┴────────┴────────┴────────┴────────┴────────┴────────┘
```

## 🔴 내부관계획에 의한 연1회 이상 점검 항목 ★★

### 문제 (2024년 기출)
```
내부관계획에 의해서 연 1회 이상 점검을 해야 하는 것이 아닌 것은?

ㄱ. 물리적 보안 점검
ㄴ. 백업 및 복구 훈련
ㄷ. 침투 테스트
ㄹ. 일일 로그 점검
```

### ✅ 정답
```
ㄹ. 일일 로그 점검

이유:
로그 점검은 연 1회가 아니라 "일일" 또는 "실시간" 점검 대상
```

### 📋 내부 관계획 점검 주기
```
┌─────────────────────┬──────────────────────┐
│       점검 항목      │      점검 주기       │
├─────────────────────┼──────────────────────┤
│ 물리적 보안 점검    │ 연 1회 이상 ✓        │
│ 백업 및 복구 훈련   │ 연 1회 이상 ✓        │
│ 침투 테스트         │ 연 1회 이상 ✓        │
│ 재해복구 훈련(BCP)  │ 연 1회 이상 ✓        │
│ 보안 감사           │ 연 1회 이상 ✓        │
├─────────────────────┼──────────────────────┤
│ 로그 점검           │ 일일 또는 실시간 ✗   │
│ 취약점 스캔         │ 월 1회 이상 ✗        │
│ 패치 관리           │ 월 1회 이상 ✗        │
│ 백업 수행           │ 일일 ✗               │
└─────────────────────┴──────────────────────┘
```

## 🔴 물리적 보안 설계 및 운영 단계 ★★

### 문제 (2024년 기출)
```
물리적 보안의 설계, 운영단계에서 알맞은 것은?

ㄱ. 설계 단계
ㄴ. 운영 단계
```

### ✅ 정답
```
설계 단계:
- 출입관리대장 작성 준비 (양식 설계)
- 출입통제시스템 설계 및 구축 계획
- 보안 구역 지정 및 등급 분류
- CCTV 배치 계획
- 생체 인증 시스템 설계

운영 단계:
- 출입통제시스템 구축 및 운영
- 출입관리대장 작성 및 관리
- 반입반출 대장 작성 및 관리
- 보안 구역 출입 통제
- CCTV 모니터링 및 영상 보관
- 정기적인 물리적 보안 점검
```

### 📊 물리적 보안 생명주기
```
[1. 설계 단계 (Plan)]
   │
   ├─ 보안 요구사항 분석
   ├─ 출입통제 정책 수립
   ├─ 시스템 설계
   │   ├─ 출입관리대장 양식
   │   ├─ 반입반출대장 양식
   │   └─ 출입통제시스템 구축 계획
   └─ 예산 및 일정 수립
   │
   ▼
[2. 구축 단계 (Do)]
   │
   ├─ 출입통제시스템 구축
   │   ├─ 카드 리더기 설치
   │   ├─ 생체 인증 시스템 설치
   │   └─ CCTV 설치
   ├─ 보안 구역 물리적 구획
   └─ 관리 절차 수립
   │
   ▼
[3. 운영 단계 (Do)]
   │
   ├─ 일상 운영
   │   ├─ 출입관리대장 작성
   │   ├─ 반입반출대장 작성
   │   ├─ 출입 승인 및 통제
   │   └─ CCTV 모니터링
   ├─ 정기 점검 (연 1회 이상)
   └─ 이상 징후 대응
   │
   ▼
[4. 점검 단계 (Check)]
   │
   ├─ 내부 감사
   ├─ 출입 기록 검토
   ├─ CCTV 영상 검토
   └─ 개선 사항 도출
   │
   ▼
[5. 개선 단계 (Act)]
   │
   ├─ 정책 및 절차 개선
   ├─ 시스템 업그레이드
   └─ 재발 방지 대책

```
✅ 일시, 성명/소속, 물품명/수량, 목적, 승인자, 일련번호, 비고

```

```

### Tip 3: 설계와 운영 구분

설계: 준비, 계획
운영: 실제 작성, 관리

✅ 설계: 대장 양식 준비
   운영: 대장 작성

## 📝 종합 문제: 물리적 보안 시나리오

### 종합 문제 1
```
신규 서버실을 구축한다. 물리적 보안 관점에서
설계 단계와 운영 단계에서 수행해야 할 작업을 각각 3가지씩 쓰시오.
```

### ✅ 답안
```
설계 단계:
1. 출입통제시스템 설계 및 구축 계획 수립
   - 카드 리더기, 생체 인증 시스템 선정
   - 출입 권한 등급 설계 (관리자, 운영자, 외부인)

2. 출입관리대장 및 반입반출대장 양식 준비
   - 필수 작성 항목 정의
   - 승인 절차 수립

3. CCTV 및 보안 구역 설계
   - CCTV 배치 계획 (사각지대 없도록)
   - 보안 구역 등급 분류 (1급, 2급, 3급)

운영 단계:
1. 출입통제시스템 구축 및 운영
   - 카드 발급 및 등록
   - 생체 정보 등록
   - 출입 권한 부여

2. 출입관리대장 및 반입반출대장 작성 관리
   - 일일 출입 기록 작성
   - 반입반출 승인 및 기록
   - 주기적 대장 검토 (월 1회)

3. 물리적 보안 정기 점검 (연 1회 이상)
   - 출입통제시스템 정상 작동 확인
   - CCTV 영상 품질 점검
   - 보안 구역 물리적 상태 점검 (잠금장치 등)
```
