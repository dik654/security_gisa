## 📝 유형 1: net 명령어형 ★★★

### 문제 1-1: 공유 폴더를 삭제하는 net 명령어를 작성하시오 (3점)

**공유 폴더 이름**: ShareData

**✅ 모범 답안**:
```cmd
net share ShareData /delete
```

**상세 설명**:
```
[net share 명령어] ★★★

# 공유 폴더 목록 확인
net share

출력 예시:
Share name   Resource        Remark
C$           C:\             Default share
ADMIN$       C:\Windows      Remote Admin
ShareData    D:\Share        공유 폴더

# 공유 폴더 생성
net share ShareName=C:\FolderPath

# 공유 폴더 삭제 ★★★
net share ShareName /delete

# 숨김 공유 생성 ($)
net share HiddenShare$=C:\Secret

# 공유 권한 설정
net share ShareName=C:\Path /GRANT:username,READ
net share ShareName=C:\Path /GRANT:username,CHANGE
net share ShareName=C:\Path /GRANT:username,FULL
```

**채점 기준**:
- 명령어 정확성 (3점)
- /delete 옵션 필수

### 문제 1-2: 사용자를 비활성화하는 net 명령어와 관리자 그룹에 추가하는 명령어를 작성하시오 (6점)

**사용자 이름**: testuser

**✅ 모범 답안**:
```cmd
# 사용자 비활성화
net user testuser /active:no

# 관리자 그룹에 추가
net localgroup Administrators testuser /add
```

**상세 설명**:
```
[net user 명령어] ★★★

# 사용자 목록
net user

# 사용자 생성
net user username password /add
net user testuser Pass123! /add

# 사용자 삭제
net user username /delete

# 사용자 비활성화 ★★★
net user username /active:no

# 사용자 활성화
net user username /active:yes

# 패스워드 변경 강제
net user username /passwordchg:yes

# 패스워드 만료 없음
net user username /expires:never

# 사용자 정보 확인
net user username

[net localgroup 명령어] ★★★

# 로컬 그룹 목록
net localgroup

# 특정 그룹 멤버 확인
net localgroup Administrators
net localgroup Users

# 그룹에 사용자 추가 ★★★
net localgroup GroupName username /add
net localgroup Administrators testuser /add

# 그룹에서 사용자 제거
net localgroup GroupName username /delete
net localgroup Administrators testuser /delete

[주요 그룹]
Administrators: 관리자 그룹
Users: 일반 사용자 그룹
Guests: 게스트 그룹
Power Users: 파워 유저 (Windows 7 이하)
Remote Desktop Users: 원격 데스크톱 허용
```

**채점 기준**:
- 비활성화 명령어 (3점)
- 그룹 추가 명령어 (3점)

### 문제 1-3: 패스워드 정책을 설정하는 net accounts 명령어를 작성하시오 (8점)

**조건**:
- 최소 길이: 10자
- 최대 사용 기간: 90일
- 계정 잠금 임계값: 5회

**✅ 모범 답안**:
```cmd
net accounts /minpwlen:10
net accounts /maxpwage:90
net accounts /lockoutthreshold:5
```

**상세 설명**:
```
[net accounts 명령어] ★★★

# 현재 정책 확인
net accounts

출력 예시:
Force user logoff how long after time expires?:       Never
Minimum password age (days):                          1
Maximum password age (days):                          90
Minimum password length:                              10
Length of password history maintained:                5
Lockout threshold:                                    5
Lockout duration (minutes):                           30
Lockout observation window (minutes):                 30
Computer role:                                        WORKSTATION

# 최소 패스워드 길이 ★★★
net accounts /minpwlen:10

# 최대 사용 기간 ★★★
net accounts /maxpwage:90    # 90일
net accounts /maxpwage:unlimited  # 무제한

# 최소 사용 기간
net accounts /minpwage:1     # 1일 (즉시 재변경 방지)

# 패스워드 이력 (재사용 금지)
net accounts /uniquepw:5     # 최근 5개 재사용 금지

# 계정 잠금 임계값 ★★★
net accounts /lockoutthreshold:5   # 5회 실패 시 잠금
net accounts /lockoutthreshold:0   # 잠금 안 함 (취약)

# 잠금 시간
net accounts /lockoutduration:30   # 30분 잠금

# 잠금 관찰 시간 (카운터 리셋)
net accounts /lockoutwindow:30     # 30분 내 5회 실패

[ISMS-P 권장 정책] ★★★
최소 길이: 10자 이상
최대 사용 기간: 90일 (일반), 60일 (특권)
최소 사용 기간: 1일
패스워드 이력: 5개
잠금 임계값: 5회
잠금 시간: 30분
```

**채점 기준**:
- 최소 길이 설정 (3점)
- 최대 사용 기간 설정 (3점)
- 잠금 임계값 설정 (2점)

### 문제 2-2: 이벤트 ID 4625 (로그인 실패)가 단시간에 많이 발생하는 경우 의심되는 공격과 대응 방안을 설명하시오 (7점)

**✅ 모범 답안**:
```
[의심되는 공격]
Brute Force Attack (무차별 대입 공격)

공격 특징:
- 짧은 시간 내 같은 계정으로 반복 로그인 시도
- 패스워드를 무작위로 대입
- 자동화 도구 사용 (Hydra, Medusa 등)
- 단일 IP 또는 분산 IP에서 시도

[대응 방안]

1. 계정 잠금 정책 설정 ★★★
   net accounts /lockoutthreshold:5
   net accounts /lockoutduration:30
   → 5회 실패 시 30분 잠금

2. 복잡한 패스워드 정책
   - 최소 길이: 10자 이상
   - 복잡도: 대소문자+숫자+특수문자

3. 2단계 인증 (MFA)
   - OTP, 생체 인증 추가
   - 패스워드만으로 로그인 불가

4. IP 차단
   - 방화벽에서 공격 IP 차단
   - Windows Firewall 규칙 추가

5. 계정 비활성화
   net user <공격대상계정> /active:no
   → 임시로 계정 비활성화

6. VPN 사용 강제
   - 외부에서 직접 로그인 차단
   - VPN 경유만 허용

7. 모니터링 및 알림
   - SIEM 도입
   - 실시간 알림 설정
   - 임계값 초과 시 자동 차단

[PowerShell 스크립트 예시]
# 최근 1시간 내 로그인 실패 5회 이상 IP 찾기
Get-EventLog -LogName Security -InstanceId 4625 `
    -After (Get-Date).AddHours(-1) |
    Group-Object -Property ReplacementStrings[19] |
    Where-Object {$_.Count -ge 5} |
    Select-Object Name, Count
```

**채점 기준**:
- 공격 유형 (Brute Force) (2점)
- 대응 방안 3가지 이상 (5점)

## 📝 유형 3: 서비스/프로세스형

### 문제 3-1: Windows의 주요 시스템 프로세스 3가지를 쓰고 각각의 역할을 설명하시오 (9점)

**✅ 모범 답안**:
```
[1. csrss.exe (Client/Server Runtime Subsystem)] ★★★
역할:
- Windows 서브시스템의 핵심 프로세스
- 콘솔 윈도우 관리
- 프로세스/스레드 생성 및 삭제
- 16비트 가상 DOS 머신(VDM) 지원

특징:
- 시스템 프로세스 (종료 불가)
- 항상 실행 중
- Session 0, Session 1 두 개 실행
- 정상 위치: C:\Windows\System32\

보안:
- 악성코드가 csrss.exe로 위장 자주
- Task Manager로 위치 확인 필수
- System32 외 다른 경로면 악성코드 의심

[2. svchost.exe (Service Host)] ★★★
역할:
- Windows 서비스를 호스팅하는 프로세스
- 여러 DLL 기반 서비스를 그룹화하여 실행
- 메모리 효율성 향상

특징:
- 여러 인스턴스가 동시 실행 (정상)
- -k 옵션으로 서비스 그룹 구분
  예: svchost.exe -k netsvcs

확인 방법:
# 각 svchost가 호스팅하는 서비스 확인
tasklist /svc

출력 예시:
svchost.exe  1234  Dhcp, Dnscache
svchost.exe  5678  WinDefend, wscsvc

보안:
- 가장 많이 위장되는 프로세스
- System32 확인 필수
- CPU/메모리 사용률 비정상 시 의심

[3. lsass.exe (Local Security Authority Subsystem Service)] ★★★
역할:
- 로컬 보안 정책 시행
- 사용자 로그온 인증
- 패스워드 변경 처리
- 액세스 토큰 생성

특징:
- 단 1개만 실행 (여러 개면 악성코드)
- 항상 실행 중
- 종료 시 시스템 재부팅

보안:
- 해커가 자주 공격하는 대상
- Mimikatz 도구가 lsass 메모리에서 패스워드 추출
- 2개 이상 실행 시 즉시 의심

[기타 주요 프로세스]
- winlogon.exe: 로그온/로그오프 처리
- services.exe: 서비스 제어 관리자
- smss.exe: Session Manager
- explorer.exe: Windows 탐색기 (사용자 프로세스)
```

**채점 기준**:
- csrss.exe 설명 (3점)
- svchost.exe 설명 (3점)
- lsass.exe 설명 (3점)

### 문제 3-2: 서비스를 자동 시작으로 변경하는 sc 명령어를 작성하시오 (4점)

**서비스 이름**: WinDefend

**✅ 모범 답안**:
```cmd
sc config WinDefend start= auto
```

**상세 설명**:
```
[sc 명령어] ★★★

# 서비스 상태 조회
sc query ServiceName
sc query WinDefend

# 모든 서비스 조회
sc query type= service state= all

# 서비스 시작
sc start ServiceName
net start ServiceName

# 서비스 중지
sc stop ServiceName
net stop ServiceName

# 서비스 설정 변경 ★★★
sc config ServiceName start= auto      # 자동
sc config ServiceName start= demand    # 수동
sc config ServiceName start= disabled  # 사용 안 함

주의: start= 에서 '=' 뒤 공백 필수!

# 서비스 설명 변경
sc description ServiceName "설명"

# 서비스 삭제
sc delete ServiceName

[서비스 시작 유형]
auto: 자동 시작
boot: 부팅 시 시작
system: 시스템 시작
demand: 수동 시작 (필요 시)
disabled: 사용 안 함
```

**채점 기준**:
- sc config 명령어 (2점)
- start= auto (2점)
- '=' 뒤 공백 확인

## 📝 유형 4: 레지스트리형

### 문제 4-1: AutoRun을 무효화하는 레지스트리 키와 값을 설명하시오 (6점)

**✅ 모범 답안**:
```
[레지스트리 경로]
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer

[값 이름]
NoDriveTypeAutoRun

[값 데이터]
255 (0xFF)

[설정 명령어]
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer" /v NoDriveTypeAutoRun /t REG_DWORD /d 255 /f

[의미]
모든 드라이브 유형에서 자동 실행 비활성화
- CD/DVD
- USB
- 네트워크 드라이브
→ 악성코드 자동 실행 방지 ★★★
```

**상세 설명**:
```
[reg 명령어] ★★★

# 레지스트리 값 추가
reg add "경로" /v 값이름 /t 유형 /d 데이터 /f

# 레지스트리 값 조회
reg query "경로" /v 값이름
reg query "HKLM\Software\Microsoft\Windows\CurrentVersion"

# 레지스트리 값 삭제
reg delete "경로" /v 값이름 /f

# 레지스트리 하이브 복사
reg copy "소스" "대상" /f

# 레지스트리 내보내기
reg export "경로" 파일명.reg

# 레지스트리 가져오기
reg import 파일명.reg

[데이터 유형]
REG_SZ: 문자열
REG_DWORD: 32비트 숫자
REG_BINARY: 이진 데이터
REG_MULTI_SZ: 여러 줄 문자열
REG_EXPAND_SZ: 확장 가능한 문자열

[주요 레지스트리 하이브]
HKEY_LOCAL_MACHINE (HKLM): 시스템 전체 설정
HKEY_CURRENT_USER (HKCU): 현재 사용자 설정
HKEY_CLASSES_ROOT (HKCR): 파일 연결 정보
HKEY_USERS (HKU): 모든 사용자 프로필
HKEY_CURRENT_CONFIG (HKCC): 현재 하드웨어 프로필

[보안 관련 레지스트리]
# 원격 데스크톱 설정
HKLM\System\CurrentControlSet\Control\Terminal Server
fDenyTSConnections = 0 (허용), 1 (차단)

# 자동 로그온 (보안 취약)
HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon
AutoAdminLogon = 1

# 시작프로그램 (악성코드 자주 등록)
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
HKLM\Software\Microsoft\Windows\CurrentVersion\Run
```

**채점 기준**:
- 레지스트리 경로 (2점)
- 값 이름 (2점)
- 값 데이터 (255) (2점)

□ 4672: 특수 권한 로그온
□ 4720: 계정 생성

### 필수 암기 프로세스 ★★★

□ lsass.exe: 로컬 보안 (1개만)
```

### 필수 암기 sc 명령어 ★★★
```
