## 📝 기출 유형 4: 포트 스캔 탐지

### 문제 4-1 (2022년 실기)
```
다음 nmap 명령어가 수행하는 스캔 유형과 특징을 설명하시오.

nmap -sS -p 1-65535 192.168.1.1
```

**✅ 답안:**
```
스캔 유형: TCP SYN Scan (Half-Open Scan)

특징:
1. -sS 옵션: SYN 스캔 (스텔스 스캔)
2. -p 1-65535: 전체 포트 스캔 (1번~65535번)
3. 동작 원리:
   - SYN 패킷만 전송
   - SYN-ACK 응답 시: 포트 열림 (OPEN)
   - RST 응답 시: 포트 닫힘 (CLOSED)
   - 무응답 시: 포트 필터링 (FILTERED)
   - 3-way handshake 완료하지 않음 (로그 회피)

장점: 빠르고, 로그에 기록되지 않을 가능성 높음
단점: root 권한 필요
```

---

### 문제 4-2 (Snort 룰)
```
포트 스캔을 탐지하는 Snort 룰을 작성하시오.

조건:
- 외부에서 내부 네트워크로의 스캔
- 30초 내 10개 이상 포트 접근 시 탐지
```

**✅ 답안:**
```
alert tcp any any -> $HOME_NET any (msg:"Port Scan Detected";
flags:S; threshold:type threshold, track by_src, count 10, seconds 30;
sid:1000001; rev:1;)

설명:
- flags:S : SYN 플래그만 있는 패킷
- threshold: 임계값 설정
  - type threshold: 임계값 도달 시 1회 경보
  - track by_src: 출발지 IP 기준 추적
  - count 10: 10회
  - seconds 30: 30초 내
```

## 📝 서술형: 포트와 보안

### 문제: 포트 기반 공격과 방어 방법

**질문:**
```
네트워크 포트를 이용한 주요 공격 유형 3가지와
각각의 방어 방법을 설명하시오.
```

**✅ 답안:**
```
1. 포트 스캐닝 (Port Scanning)
   공격 방법:
   - nmap, masscan 등 도구 사용
   - 열린 포트 탐색 (정찰 단계)
   - SYN Scan, FIN Scan, XMAS Scan 등

   방어 방법:
   - 불필요한 포트 닫기
   - 방화벽에서 포트 스캔 탐지 룰 설정
   - IDS/IPS로 스캔 행위 탐지 (threshold 설정)
   - 포트 필터링 (stealth 모드)

2. 서비스 거부 공격 (DoS/DDoS)
   공격 방법:
   - SYN Flooding (TCP 80, 443 등)
   - UDP Flooding (DNS 53)
   - 대량 연결 요청으로 서비스 마비

   방어 방법:
   - SYN Cookie 활성화
   - Rate Limiting (연결 속도 제한)
   - DDoS 방어 장비 (Arbor, Radware)
   - CDN 활용 (Cloudflare, Akamai)

3. 서비스 취약점 공격
   공격 방법:
   - 알려진 포트의 서비스 취약점 공격
   - 예: MS SQL (1433) 버퍼 오버플로우
   - SMB (445) EternalBlue (WannaCry)

   방어 방법:
   - 정기적인 보안 패치 적용
   - 서비스 버전 숨기기 (배너 그래빙 방지)
   - 최소 권한 원칙 (서비스 계정 권한 제한)
   - 불필요한 서비스 중지
```

## 📊 그림으로 이해하기

### TCP 3-Way Handshake (포트 연결 과정)
```
클라이언트                          서버
   │                                 │
   │  SYN (seq=100)                 │
   │ ──────────────────────────────>│ (포트 80 LISTEN)
   │                                 │
   │             SYN-ACK (seq=200,   │
   │                      ack=101)   │
   │ <──────────────────────────────│
   │                                 │
   │  ACK (ack=201)                 │
   │ ──────────────────────────────>│
   │                                 │
   │  연결 설정 완료 (ESTABLISHED)  │
   │                                 │
   │  HTTP 요청/응답                │
   │ <─────────────────────────────>│
```

### 포트 스캔 유형별 패킷
```
[TCP SYN Scan (Half-Open)]
클라이언트 → 서버: SYN
서버 → 클라이언트: SYN-ACK (포트 열림)
클라이언트 → 서버: RST (연결 중단, 로그 회피)

[TCP FIN Scan]
클라이언트 → 서버: FIN
서버 응답 없음: 포트 열림 (정상 동작 아니므로 무시)
서버 → 클라이언트: RST: 포트 닫힘

[TCP XMAS Scan]
클라이언트 → 서버: FIN+PSH+URG (크리스마스 트리처럼 플래그 켜짐)
서버 응답 없음: 포트 열림
서버 → 클라이언트: RST: 포트 닫힘

[UDP Scan]
클라이언트 → 서버: UDP 패킷
서버 → 클라이언트: ICMP Port Unreachable: 포트 닫힘
서버 응답 없음: 포트 열림 또는 필터링
```

### 방화벽 포트 필터링
```
[Default Deny 정책]

인터넷                방화벽                내부망
   │                    │                    │
   │ HTTP (80) 요청    │                    │
   ├──────────────────>│ 정책 1: 허용       │
   │                    ├──────────────────>│ 웹서버
   │                    │                    │
   │ SSH (22) 요청     │                    │
   ├──────────────────>│ 정책 2: 차단       │
   │                    │ (DROP)             │
   │                    │                    │
   │ Telnet (23) 요청  │                    │
   ├──────────────────>│ 정책 3: 거부       │
   │ <──────────────────│ (REJECT, RST 응답) │

정책 우선순위: 1 → 2 → 3 → Default Deny
```

## 💡 실기 답안 작성 팁

### Tip 1: 포트 번호는 숫자로만
```
✅ 22
✅ 443
❌ twenty-two (X)
❌ 22번 포트 (불필요한 설명)
```

### Tip 2: 프로토콜 명시
```
✅ 53/UDP, 53/TCP
✅ TCP 22
❌ 22 (프로토콜 누락 시 감점 가능)
```

### Tip 3: 서비스명은 정확히
```
✅ SSH (Secure Shell)
✅ HTTPS (HTTP Secure)
❌ Secure SHell (대소문자 틀림)
```

### Tip 4: 포트 범위 표현
```
Well-Known Ports: 0-1023
Registered Ports: 1024-49151
Dynamic/Private Ports: 49152-65535

✅ "1-65535" (전체 포트)
✅ "1-1023" (Well-Known)
```
