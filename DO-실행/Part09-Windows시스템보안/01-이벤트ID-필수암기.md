## 📝 기출 유형 3: 로그 분석

### 문제 3-1 (종합 문제)
```
다음은 Windows 보안 로그의 일부이다.
물음에 답하시오.

이벤트 ID: 4625
날짜/시간: 2024-01-15 14:35:22
계정 이름: admin
로그온 유형: 3
실패 원인: 0xC000006D

이벤트 ID: 4625
날짜/시간: 2024-01-15 14:35:30
계정 이름: admin
로그온 유형: 3
실패 원인: 0xC000006D

이벤트 ID: 4625
날짜/시간: 2024-01-15 14:35:35
계정 이름: admin
로그온 유형: 3
실패 원인: 0xC000006D

이벤트 ID: 4740
날짜/시간: 2024-01-15 14:35:35
계정 이름: admin

1) 어떤 공격이 의심되는가?
2) 시스템이 취한 조치는 무엇인가?
3) 추가로 확인해야 할 사항은?
```

**✅ 답안:**
```
1) 의심되는 공격:
   Brute Force Attack (무차별 대입 공격)
   - admin 계정에 대한 연속된 로그인 실패 (4625)
   - 짧은 시간 내 여러 번 시도 (8초 내 3회)

2) 시스템 조치:
   계정 잠금 (4740)
   - 로그인 실패 임계값 초과로 admin 계정 자동 잠금

3) 추가 확인 사항:
   - 로그온 유형 3 → 네트워크 로그온
   - 출발지 IP 주소 확인 (공격자 위치)
   - 실패 원인 0xC000006D → "잘못된 사용자 이름 또는 암호"
   - 다른 계정도 동일한 IP에서 시도했는지 확인
   - 방화벽에서 해당 IP 차단 고려
```

**📌 로그온 유형 (Logon Type):**
```
2  → 대화형 (Interactive) - 콘솔 로그인
3  → 네트워크 (Network) - 네트워크를 통한 접근 ★
4  → 일괄 처리 (Batch)
5  → 서비스 (Service)
7  → 잠금 해제 (Unlock)
8  → NetworkCleartext - 평문 암호 전송
10 → RemoteInteractive (RDP) - 원격 데스크톱 ★
11 → CachedInteractive - 캐시된 자격 증명
```

## 📝 기출 유형 4: 이벤트 로그 설정

### 문제 4-1
```
Windows 보안 로그의 최대 크기를 10MB로 설정하고,
로그가 가득 찰 경우 덮어쓰지 않도록 설정하시오.
설정 방법을 단계별로 쓰시오.
```

**✅ 답안:**
```
방법 1: 이벤트 뷰어 (GUI)
1. eventvwr.msc 실행
2. Windows 로그 → 보안 우클릭 → 속성
3. 최대 로그 크기: 10240 KB (10MB) 입력
4. "최대 이벤트 로그 크기에 도달하면" 섹션에서
   "로그 보관(덮어쓰지 않음)" 선택
5. 확인

방법 2: PowerShell
$logName = "Security"
$log = New-Object System.Diagnostics.Eventing.Reader.EventLogConfiguration $logName
$log.MaximumSizeInBytes = 10485760  # 10MB
$log.LogMode = "Retain"              # 덮어쓰지 않음
$log.SaveChanges()

방법 3: wevtutil 명령어
wevtutil sl Security /ms:10485760 /rt:false
```

## 📝 기출 유형 5: 이벤트 ID 조합 분석

### 문제 5-1
```
다음 이벤트 ID 순서를 보고 어떤 작업이 수행되었는지 설명하시오.

4720 → 4732 → 4624 → 4672
```

**✅ 답안:**
```
1. 4720: 새로운 사용자 계정 생성
2. 4732: 해당 사용자를 로컬 그룹(Administrators)에 추가
3. 4624: 사용자가 로그온 성공
4. 4672: 관리자 권한으로 로그온

전체 시나리오:
관리자가 새로운 사용자 계정을 생성하고,
Administrators 그룹에 추가한 후,
해당 사용자로 관리자 권한 로그온을 수행함.
```

   - 계정 잠금 카운터 다시 설정: 60분

   - 4625: 로그온 실패 (각 실패 시도마다)
