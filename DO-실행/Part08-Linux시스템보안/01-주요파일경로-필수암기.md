# Linux 주요 파일 경로 - 필수 암기 (실기 빈출!)

## 🔴 반드시 암기해야 하는 파일 경로 Top 20

### 계정 관련 파일
```
/etc/passwd          → 사용자 계정 정보 (권한: 644)
/etc/shadow          → 암호화된 패스워드 (권한: 400, root만)
/etc/group           → 그룹 정보
/etc/gshadow         → 그룹 패스워드
/etc/login.defs      → 패스워드 정책 설정
/etc/securetty       → root 로그인 가능한 터미널
```

### 로그 파일 🔴 매우 중요!
```
/var/log/messages    → 시스템 전반적인 로그 (CentOS/RHEL)
/var/log/syslog      → 시스템 로그 (Ubuntu/Debian)
/var/log/secure      → 인증 관련 로그 (SSH, su, sudo) ★★★
/var/log/auth.log    → 인증 로그 (Ubuntu/Debian)
/var/log/wtmp        → 로그인/로그아웃 기록
/var/log/btmp        → 실패한 로그인 기록 (5회 이상)
/var/log/lastlog     → 마지막 로그인 정보
/var/log/utmp        → 현재 로그인 중인 사용자
/var/log/acct        → 프로세스 계정 정보
/var/log/pacct       → 프로세스 실행 기록
```

### 네트워크 및 보안 설정
```
/etc/hosts           → IP-호스트명 매핑
/etc/hosts.allow     → 접근 허용 호스트 (tcpwrapper)
/etc/hosts.deny      → 접근 거부 호스트
/etc/resolv.conf     → DNS 서버 설정
/etc/ssh/sshd_config → SSH 서버 설정 ★★★
/etc/ssh/ssh_config  → SSH 클라이언트 설정
```

### PAM 및 인증
```
/etc/pam.d/          → PAM 설정 파일 디렉토리
/lib/security/       → PAM 모듈 위치
/lib64/security/     → 64비트 PAM 모듈
/etc/security/       → PAM 추가 설정
```

### 시스템 관리
```
/etc/fstab           → 파일시스템 자동 마운트
/etc/crontab         → 시스템 cron 스케줄
/etc/cron.allow      → cron 사용 허용 사용자
/etc/cron.deny       → cron 사용 거부 사용자
/etc/sudoers         → sudo 권한 설정
```

## 📝 기출 유형 2: /etc/passwd 파일 형식

### 문제 2-1 (기출 변형)
```
다음은 /etc/passwd 파일의 한 줄이다. 각 필드를 설명하시오.

root:x:0:0:root:/root:/bin/bash
```

**✅ 답안:**
```
┌──────┬───┬───┬───┬──────┬───────┬──────────┐
│사용자│비밀│UID│GID│GECOS │  홈   │  쉘      │
│이름  │번호│   │   │      │디렉토리│         │
├──────┼───┼───┼───┼──────┼───────┼──────────┤
│root  │ x │ 0 │ 0 │root  │/root  │/bin/bash │
└──────┴───┴───┴───┴──────┴───────┴──────────┘

1. root       : 사용자 이름
2. x          : 패스워드 (x는 /etc/shadow에 저장됨을 의미)
3. 0          : UID (User ID, 0은 root)
4. 0          : GID (Group ID, 0은 root 그룹)
5. root       : GECOS (사용자 설명, 이름, 전화번호 등)
6. /root      : 홈 디렉토리
7. /bin/bash  : 로그인 쉘
```

**📌 중요 UID:**
```
0        : root (슈퍼유저)
1-99     : 시스템 계정
100-999  : 시스템 계정 (최신)
1000+    : 일반 사용자
```

### 문제 2-2
```
/etc/shadow 파일의 형식을 설명하고,
패스워드 유효기간을 90일로 설정한 예를 쓰시오.
```

**✅ 답안:**
```
형식:
username:$암호화방식$salt$해시:lastchange:min:max:warn:inactive:expire:reserved

예시:
user01:$6$abc...:18500:1:90:7:::

필드 설명:
1. user01     : 사용자명
2. $6$abc...  : 암호화된 패스워드 ($6$ = SHA-512)
3. 18500      : 마지막 패스워드 변경일 (1970.1.1부터 일수)
4. 1          : 최소 사용일 (변경 후 1일 이내 재변경 불가)
5. 90         : 최대 사용일 (90일마다 변경) ★
6. 7          : 경고 일수 (만료 7일 전 경고)
7. (빈칸)     : 비활성화 기간
8. (빈칸)     : 계정 만료일
9. (빈칸)     : 예약 필드
```

## 📝 기출 유형 4: 파일 권한 및 소유자

### 문제 4-1 (KISA 가이드라인)
```
/etc/passwd와 /etc/shadow 파일의 적절한 권한과
소유자를 각각 쓰시오.
```

**✅ 답안:**
```
/etc/passwd
- 소유자: root
- 권한: 644 (rw-r--r--)
- 이유: 일반 사용자도 읽기 가능 (사용자 정보 확인 필요)

/etc/shadow
- 소유자: root
- 권한: 400 (r--------) 또는 000 (---------)
- 이유: root만 읽기 가능 (암호화된 패스워드 보호)
```

**설정 명령어:**
```bash
chown root:root /etc/passwd
chmod 644 /etc/passwd

chown root:root /etc/shadow
chmod 400 /etc/shadow
```

---

### 문제 4-2
```
/var/log/secure 파일의 적절한 권한을 쓰고,
그 이유를 설명하시오.
```

**✅ 답안:**
```
권한: 640 (rw-r-----)

이유:
- 소유자(root): 읽기/쓰기 가능
- 그룹: 읽기만 가능 (로그 분석 담당자)
- 기타 사용자: 접근 불가 (민감한 인증 정보 포함)

설정:
chmod 640 /var/log/secure
```

## 📝 서술형: SSH 보안 설정

### 문제 5-1 (종합 문제)
```
SSH 서버의 보안을 강화하기 위해 다음 사항을 설정하시오.

1) root 계정의 원격 로그인을 차단
2) 패스워드 인증을 비활성화하고 공개키 인증만 허용
3) SSH 포트를 22에서 2222로 변경

설정 파일 경로와 변경할 설정을 쓰시오.
```

**✅ 답안:**
```
파일 경로: /etc/ssh/sshd_config

설정 변경:
1) PermitRootLogin no
2) PasswordAuthentication no
3) Port 2222

설정 적용:
systemctl restart sshd
또는
service sshd restart
```

**전체 설정 예시:**
```bash
# /etc/ssh/sshd_config

Port 2222                           # 포트 변경
Protocol 2                          # SSH v2만 사용
PermitRootLogin no                  # root 원격 로그인 차단
PasswordAuthentication no           # 패스워드 인증 비활성화
PubkeyAuthentication yes            # 공개키 인증 활성화
PermitEmptyPasswords no             # 빈 패스워드 금지
MaxAuthTries 3                      # 최대 인증 시도 3회
LoginGraceTime 60                   # 인증 제한 시간 60초
ClientAliveInterval 300             # 클라이언트 체크 주기
ClientAliveCountMax 0               # 무응답시 즉시 종료
```

## 🎯 실기 답안 작성 팁

### Tip 1: 경로는 정확하게
```
✅ /etc/ssh/sshd_config
❌ /etc/sshd_config
❌ /etc/ssh/sshd.conf
❌ etc/ssh/sshd_config (앞에 / 빠짐)
```

### Tip 2: 권한은 3자리 숫자로
```
✅ 644
✅ 400
❌ rw-r--r-- (숫자로 쓰는 게 명확)
```

### Tip 3: 명령어는 정확한 옵션까지
```
✅ chmod 644 /etc/passwd
❌ chmod /etc/passwd (권한 누락)

✅ systemctl restart sshd
❌ restart sshd (명령어 누락)
```

### Tip 4: 여러 답이 가능한 경우
```
문제: "로그 파일의 권한을 쓰시오"
답안: 640 또는 600 (둘 다 정답으로 인정 가능)

문제: "/etc/shadow의 권한은?"
답안: 400 또는 000 (둘 다 정답)
```

## 📊 그림으로 이해하기

### /etc/passwd vs /etc/shadow
```
[초기 Unix]
/etc/passwd에 모든 정보 저장
문제: 모든 사용자가 암호화된 패스워드 볼 수 있음
     → Rainbow Table 공격 가능

[현대 Linux]
/etc/passwd (644)          /etc/shadow (400)
┌──────────────┐          ┌─────────────────┐
│user:x:1000:..│   x →    │user:$6$salt$hash│
│             │          │    :18500:1:90:7│
│모든 사용자    │          │                 │
│읽기 가능      │          │  root만 읽기    │
└──────────────┘          └─────────────────┘

보안 강화: 패스워드를 별도 파일로 분리
```

### 로그 파일 구조
```
/var/log/
├── messages    → 시스템 전반 (INFO 레벨)
├── secure      → 인증 (su, sudo, SSH) ★★★
├── wtmp        → 로그인 성공 (binary)
├── btmp        → 로그인 실패 (binary) ★
├── lastlog     → 마지막 로그인 (binary)
├── utmp        → 현재 로그인 (binary)
└── cron        → cron 작업

조회 명령어:
messages → tail -f /var/log/messages
secure   → tail -f /var/log/secure
wtmp     → last
btmp     → lastb ★
lastlog  → lastlog
utmp     → who, w
```

## 🔥 실기 시험 최빈출 경로 (꼭 외우기!)

```
1. /etc/ssh/sshd_config       ← SSH 설정 (매년 출제!)
2. /var/log/secure            ← 인증 로그 (매년 출제!)
3. /etc/shadow                ← 패스워드 파일
4. /etc/passwd                ← 사용자 계정
5. /var/log/messages          ← 시스템 로그
6. /etc/hosts.allow/deny      ← tcpwrapper
7. /etc/login.defs            ← 패스워드 정책
8. /etc/pam.d/                ← PAM 설정
9. /var/log/btmp              ← 실패 로그인
10. /etc/resolv.conf          ← DNS 설정
```

**✅ 이 10개만 정확히 외우면 경로 문제는 거의 다 맞출 수 있습니다!**
