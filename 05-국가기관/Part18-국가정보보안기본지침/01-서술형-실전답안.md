## 1. 국가정보보안기본지침 개요

### 문제 1. 적용 대상 및 법적 근거 (10점) ★★★

**문제**:
국가정보보안기본지침의 법적 근거와 적용 대상을 설명하시오. (10점)

**✅ 모범 답안**:

#### 법적 근거 - 3점 ★★★

```
국가사이버안전관리규정 제8조
```

**관련 법령 체계**:
```
1. 국가사이버안전관리규정 (대통령령)
   ↓
2. 국가정보보안기본지침 (국가정보원 고시)
   ↓
3. 각 기관별 세부 지침
```

#### 적용 대상 - 5점 ★★★

**1. 국가기관** - 2점
```
- 중앙행정기관
  (행정안전부, 국방부, 외교부 등)
- 국회
- 법원
- 헌법재판소
- 선거관리위원회
```

**2. 지방자치단체** - 2점
```
- 시·도 (광역자치단체)
- 시·군·구 (기초자치단체)
```

**3. 공공기관** - 1점
```
- 공공기관의 운영에 관한 법률에 따른 공공기관
  (한국전력공사, 한국철도공사 등)
```

#### 적용 범위 - 2점

**포함**:
```
✅ 모든 국가 공공기관
✅ 정보통신망
✅ 정보시스템
✅ 국가 정보자산
```

**제외**:
```
❌ 민간 기업 (ISMS-P 적용)
❌ 개인
```

---

**채점 기준**:
- 법적 근거 (국가사이버안전관리규정) (3점)
- 적용 대상 3가지 정확히 기재 (6점)
- 적용 범위 설명 (1점)

**핵심 요약**:
```
법적 근거: ★★★
국가사이버안전관리규정 제8조

적용 대상: ★★★
1. 국가기관 (중앙행정기관, 국회, 법원 등)
2. 지방자치단체 (시·도, 시·군·구)
3. 공공기관

vs 민간: ISMS-P 적용
```

**암기 팁**:
```
"국지공" (국가기관, 지방자치단체, 공공기관)
```

## 2. 정보자산 분류

### 문제 2. 비밀 등급 체계 (15점) ★★★

**문제**:
국가정보보안기본지침에 따른 비밀 등급 체계(I급, II급, III급 비밀, 대외비)를 설명하시오. (15점)

**✅ 모범 답안**:

#### I급 비밀 - 4점 ★★★

**정의**:
```
누설 시 국가안전보장에 치명적인 위험 초래
```

**특징**:
```
- 최고 등급
- 가장 엄격한 관리
- 제한적 접근
```

**보호 기간**:
```
30년 ★★★
```

**예시**:
```
- 전시 작전계획
- 국가 핵심기술
- 최고위급 외교 문서
- 국가안보 핵심 정보
```

**관리 요구사항**:
```
- 별도 보관 시설
- 이중 잠금장치
- 접근 기록 엄격 관리
- 반출 시 최고위급 승인
```

#### II급 비밀 - 4점 ★★★

**정의**:
```
누설 시 국가안전보장에 상당한 위험 초래
```

**보호 기간**:
```
20년 ★★★
```

**예시**:
```
- 국방 무기체계
- 외교 협상 문서
- 주요 국가 정책
- 군사 작전 정보
```

**관리 요구사항**:
```
- 보안 구역 보관
- 잠금장치
- 접근 통제
- 반출 시 승인 필요
```

#### III급 비밀 - 3점 ★★★

**정의**:
```
누설 시 국가안전보장에 해로움
```

**보호 기간**:
```
10년 ★★★
```

**예시**:
```
- 일반 군사 정보
- 행정 기밀
- 보안 관련 문서
- 대외 비공개 정보
```

**관리 요구사항**:
```
- 지정된 보관함
- 기본 잠금장치
- 접근 권한 관리
```

#### 대외비 - 4점 ★★

**정의**:
```
공개 시 업무 수행에 지장 초래
비밀은 아니나 공개 부적절한 정보
```

**특징**:
```
- 비밀이 아님 (중요!)
- 행정 목적의 비공개
- 상대적으로 낮은 보호 수준
```

**보호 기간**:
```
기관장이 정함 (재량)
```

**예시**:
```
- 내부 업무 자료
- 개인정보 포함 문서
- 미공개 정책 검토 자료
- 입찰 관련 정보
```

**관리 요구사항**:
```
- 일반 보관함
- 기본 접근 통제
- 외부 공개 제한
```

#### 비교 요약표

| 등급 | 정의 | 보호 기간 | 비고 |

## 3. 취약점 분석 및 평가

### 문제 3. 주요정보통신기반시설 보호 (15점) ★★★

**문제**:
정보통신기반보호법에 따른 주요정보통신기반시설의 취약점 분석/평가 의무를 설명하시오. (15점)

**✅ 모범 답안**:

#### 주요정보통신기반시설 정의 - 5점 ★★★

**정의**:
```
전자적 제어·관리시스템 또는 정보통신망으로서
파괴·마비 시 국가안전보장, 경제·사회에
심각한 영향을 미칠 수 있는 시설
```

**8대 분야**: ★★★
```
1. 정보통신 (통신망, 데이터센터)
2. 금융 (은행, 증권, 결제)
3. 교통 (항공, 철도, 지능형 교통)
4. 에너지/전력 (발전소, 송배전)
5. 수도 (정수장, 상수도)
6. 가스 (가스 공급망)
7. 의료 (병원 정보시스템)
8. 방송 (방송국, 송출)
```

**암기**: "정금교전수가의방"

#### 취약점 분석/평가 의무 - 10점 ★★★

2. 외부 전문기관 위탁

**분석 대상** - 4점
```

   - 보안 교육 현황
   - 문서화 수준

2. 물리적 취약점
   - 출입통제 시스템
   - CCTV
   - 전산실 보안
   - 재해 대비

3. 기술적 취약점 ★★★
   - 네트워크 구성
   - 시스템 보안 설정
   - 소프트웨어 취약점
   - 패치 관리
   - 접근통제
   - 암호화 적용
   - 악성코드 대응
   - 로그 관리
```

## 4. 암호장비 관리

### 문제 4. 국가정보원 승인 암호장비 (10점) ★★

**문제**:
국가정보보안기본지침에 따른 암호장비 관리 요구사항을 설명하시오. (10점)

**✅ 모범 답안**:

#### 암호장비 사용 원칙 - 3점 ★★★

**사용 의무**:
```
국가기관은 국가정보원장이 승인한
암호장비를 사용해야 함 ★★★
```

**승인 암호장비**:
```
- 국가정보원의 검증을 거친 암호장비
- 보안성이 확인된 제품
- 국가 보안 기준 충족
```

#### 암호키 관리 - 5점 ★★★

**1. 암호키 생성** - 1점
```
- 안전한 난수 생성기 사용
- 충분한 키 길이
- 예측 불가능성 보장
```

**2. 암호키 분배** - 2점 ★★★
```
- 안전한 채널 사용
- 암호화된 전송
- 권한자만 접근
- 키 분배 기록 유지
```

**3. 암호키 보관** - 1점
```
- 물리적 보안 (금고, HSM)
- 암호화하여 저장
- 접근 통제
- 백업 키 보관 (별도 장소)
```

**4. 암호키 사용** - 1점
```
- 목적에 맞게만 사용
- 키 분리 (서명 키 ≠ 암호화 키)
- 사용 기록 유지
```

**5. 암호키 변경** - 1점 ★★
```
- 주기적 변경 (권장: 1년)
- 침해 의심 시 즉시 변경
- 퇴직/전보 시 변경
```

**6. 암호키 파기** - 1점 ★★★
```
- 사용 종료 시 즉시 파기
- 복구 불가능하게 삭제
- 파기 기록 유지
- 백업 키도 함께 파기
```

#### 암호장비 관리 - 2점

```
1. 등록 관리
   - 암호장비 목록 작성
   - 사용자 지정
   - 위치 관리

2. 점검
   - 정기 점검 (분기 1회 권장)
   - 이상 여부 확인
   - 기록 유지

3. 반출입 통제
   - 반출 시 승인
   - 반출입 기록
   - 분실 시 즉시 보고

4. 폐기
   - 승인 후 폐기
   - 데이터 완전 삭제
   - 폐기 기록
```

---

**채점 기준**:
- 국가정보원 승인 암호장비 사용 의무 (3점)
- 암호키 생명주기 관리 (생성, 분배, 보관, 변경, 파기) (5점)
- 암호장비 관리 (2점)

**핵심 요약**:
```
암호장비 사용: ★★★
국가정보원장 승인 암호장비 의무

암호키 관리 (생명주기): ★★★
1. 생성: 안전한 난수
2. 분배: 안전한 채널 ★★★
3. 보관: HSM, 금고
4. 사용: 목적별 분리
5. 변경: 주기적 (1년 권장)
6. 파기: 복구 불가능하게 ★★★

암호장비 관리:
- 등록, 점검, 반출입 통제, 폐기
```

**암기 팁**:
```
"생분보사변파"
(생성, 분배, 보관, 사용, 변경, 파기)
```
