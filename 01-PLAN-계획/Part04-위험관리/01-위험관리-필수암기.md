# Part 4. 위험관리 - 필수 암기

> **PDCA 사이클**: PLAN (계획) 단계
> **시험 중요도**: ★★★ (매년 7-12문항 출제)

---

## 🎯 핵심 암기 사항

### 위험 = 자산가치 × 위협 × 취약점 ★★★

```
위험도 계산 공식:
Risk = Asset Value × Threat × Vulnerability

예시:
자산가치(5) × 위협(3) × 취약점(4) = 위험도(60)
```

### 위험대응 전략 4가지 ★★★

```
1. 회피 (Avoid)   - 위험한 활동 중단 ★★
2. 전가 (Transfer) - 보험, 아웃소싱 ★★★
3. 감소 (Mitigate) - 보안대책 구현 ★★★
4. 수용 (Accept)  - 일정 수준 위험 감수 ★★

← 2024년 실기 필수 암기!
```

### 위험평가 방법론 비교 ★★★

```
베이스라인 접근법 (Baseline)
- 표준화된 보안대책 체크리스트
- 빠르고 간편
- 조직 특성 반영 어려움 ★★

비정형 접근법 (Informal)
- 전문가 경험과 판단
- 유연하지만 일관성 부족 ★

상세 위험분석 (Detailed Risk Analysis)
- 자산→위협→취약점→위험도 산정
- 정확하지만 시간/비용 多 ★★★

복합 접근법 (Combined)
- 위 3가지 혼합
- 가장 효과적 ★★★
```

## 📝 실기 기출문제

### 문제 1. 위험도 계산 ★★★

**문제**: 다음 조건에서 위험도를 계산하시오.
- 자산가치: 5 (중요)
- 위협 발생 가능성: 3 (보통)
- 취약점 심각도: 4 (높음)

**✅ 정답**:
```
위험도 = 자산가치 × 위협 × 취약점
       = 5 × 3 × 4
       = 60
```

**상세 설명**:
- 위험도 등급 분류:
  - 상 (High): 60 이상
  - 중 (Medium): 30~59
  - 하 (Low): 29 이하
- 2024년 실기 출제 ★★★

---

### 문제 2. 위험대응 전략 ★★★

**문제**: 다음 상황에 적합한 위험대응 전략을 쓰시오.

(1) 해킹 위험이 높은 온라인 서비스를 중단
(2) 화재 위험에 대비해 보험 가입
(3) SQL Injection 방어를 위해 Prepared Statement 적용
(4) 낮은 수준의 위험을 그대로 수용

**✅ 정답**:
```
(1) 회피 (Risk Avoidance)
(2) 전가 (Risk Transfer)
(3) 감소/완화 (Risk Mitigation)
(4) 수용 (Risk Acceptance)
```

**상세 설명**:
- 각 전략의 특징:
  - 회피: 가장 확실하지만 업무 제한
  - 전가: 비용 발생하지만 책임 이전
  - 감소: 가장 일반적인 방법 ★★★
  - 수용: 비용 효율적, 잔여위험 관리
- 2024년 실기 빈출 ★★★

### 문제 3. 잔여위험 (Residual Risk) ★★

**문제**: 잔여위험(Residual Risk)의 정의를 설명하시오.

**✅ 정답**:
```
보안대책을 적용한 후에도 남아있는 위험

또는

위험 감소 조치 후 수용하기로 결정한 위험
```

**상세 설명**:
```
초기 위험(100) - 보안대책(70) = 잔여위험(30)

잔여위험 관리:
1. 추가 보안대책 검토
2. 경영진 승인 후 수용
3. 주기적 모니터링
```
- 2023년 실기 출제 ★★

### 문제 4. 위험평가 절차 ★★★

**문제**: 상세 위험분석(Detailed Risk Analysis) 방법론의 4단계 절차를 순서대로 쓰시오.

**✅ 정답**:
```
1. 자산 식별 (Asset Identification)
2. 위협 식별 (Threat Identification)
3. 취약점 분석 (Vulnerability Analysis)
4. 위험도 산정 (Risk Assessment)
```

**상세 설명**:
- 자산 식별: 정보자산, 물리적 자산, 인적 자산
- 위협 식별: 자연적, 인적, 환경적 위협
- 취약점 분석: KISA 점검 가이드, CVE 등
- 위험도 산정: 자산×위협×취약점
- 2024년 실기 출제 ★★★

### 문제 5. 위협의 종류 ★★

**문제**: 위협(Threat)을 3가지 유형으로 분류하고 각각의 예를 들어 설명하시오.

**✅ 정답**:
```
1. 자연적 위협 (Natural Threat)
   예: 지진, 홍수, 화재, 태풍

2. 인적 위협 (Human Threat)
   예: 해킹, 내부자 공격, 사회공학

3. 환경적 위협 (Environmental Threat)
   예: 정전, 온습도 이상, 통신 장애
```

**상세 설명**:
- 인적 위협이 가장 대응 어려움
- 내부자 위협 > 외부자 위협 (권한 보유)
- 2023년 실기 출제 ★★

### 문제 6. CIA Triad ★★★

**문제**: 정보보호의 3대 목표인 CIA Triad를 쓰고 각각 설명하시오.

**✅ 정답**:
```
C (Confidentiality, 기밀성)
- 인가된 사용자만 정보 접근
- 예: 암호화, 접근통제

I (Integrity, 무결성)
- 정보의 정확성과 완전성 보장
- 예: 해시, 전자서명

A (Availability, 가용성)
- 필요 시 정보 사용 가능
- 예: 백업, 이중화
```

**상세 설명**:
- 추가 개념 (확장):
  - Authenticity (진정성): 정보 출처 확인
  - Non-repudiation (부인방지): 행위 부인 불가
  - Accountability (책임추적성): 행위 추적
- 2024년 실기 필수 ★★★

### 문제 7. 자산 분류 기준 ★★

**문제**: 정보자산의 중요도를 평가하는 기준 3가지를 CIA 관점에서 설명하시오.

**✅ 정답**:
```
1. 기밀성 (Confidentiality)
   - 유출 시 조직에 미치는 영향

2. 무결성 (Integrity)
   - 위변조 시 업무에 미치는 영향

3. 가용성 (Availability)
   - 중단 시 서비스에 미치는 영향
```

**상세 설명**:
```
평가 척도 예시:
상 (High): 매우 치명적 (5점)
중 (Medium): 보통 영향 (3점)
하 (Low): 경미한 영향 (1점)

자산가치 = (기밀성 + 무결성 + 가용성) / 3
```
- 2023년 실기 출제 ★★

## 🔴 위험관리 상세 개념

### 1. 위험평가 방법론 비교 ★★★

#### 베이스라인 접근법 (Baseline Approach) ★★

**개념**:
```
표준화된 보안대책 체크리스트를 기반으로
조직에 일괄 적용
```

**장점**:
```
✓ 빠르고 간편
✓ 비용 효율적
✓ 일관성 유지
✓ 초보자도 수행 가능
```

**단점**:
```
✗ 조직 특성 반영 어려움
✗ 불필요한 통제 적용 가능
✗ 새로운 위협 대응 미흡
```

**적용 예**:
```
- ISMS-P 인증기준 102개 항목 전체 적용
- KISA 취약점 점검 가이드 일괄 적용
- CIS Controls 20개 전체 적용
```

**실기 출제 경향**: ★★
- "베이스라인 접근법의 장단점은?"
- "빠르고 간편한 위험평가 방법은?"

---

#### 비정형 접근법 (Informal Approach) ★

**개념**:
```
보안 전문가의 경험과 직관에 의존
체계적 절차 없이 판단
```

**장점**:
```
✓ 유연성
✓ 신속한 대응
✓ 전문가 경험 활용
```

**단점**:
```
✗ 일관성 부족
✗ 주관적 판단
✗ 문서화 미흡
✗ 재현성 낮음
```

**적용 예**:
```
- 소규모 조직
- 긴급 상황
- 초기 검토 단계
```

**실기 출제 경향**: ★ (드물게 출제)

---

#### 상세 위험분석 (Detailed Risk Analysis) ★★★

**개념**:
```
체계적이고 정량적인 위험분석
자산→위협→취약점→위험도 산정 4단계
```

**절차**:
```
1단계: 자산 식별
- 정보자산 목록 작성
- 중요도 평가 (CIA 기준)
- 자산 담당자 지정

2단계: 위협 식별
- 자연적 위협 (재해, 화재)
- 인적 위협 (해킹, 내부자)
- 환경적 위협 (정전, 장애)
- 위협 발생 가능성 평가 (상/중/하)

3단계: 취약점 분석
- 기술적 취약점 (패치 누락, 설정 오류)
- 관리적 취약점 (정책 부재, 교육 미흡)
- 물리적 취약점 (출입통제 미비)
- 취약점 심각도 평가 (상/중/하)

4단계: 위험도 산정
- 위험도 = 자산가치 × 위협 × 취약점
- 위험 우선순위 결정
- 보안대책 수립
```

**장점**:
```
✓ 정확하고 신뢰성 높음
✓ 조직 특성 반영
✓ 경영진 의사결정 지원
✓ 문서화 체계적
```

**단점**:
```
✗ 시간 많이 소요
✗ 비용 높음
✗ 전문가 필요
✗ 유지관리 부담
```

**실기 출제 경향**: ★★★
- "상세 위험분석의 4단계 절차는?"
- "위험도 계산 공식은?"
- 가장 많이 출제되는 방법론

---

#### 복합 접근법 (Combined Approach) ★★★

**개념**:
```
베이스라인 + 상세 위험분석 혼합
일반 자산은 베이스라인, 중요 자산은 상세 분석
```

**장점**:
```
✓ 효율성과 정확성 균형
✓ 가장 실용적
✓ 비용 대비 효과 우수
```

**적용 예**:
```
일반 서버: 베이스라인 (KISA 가이드)
핵심 DB: 상세 위험분석
사무실 PC: 비정형 접근법
```

**실기 출제 경향**: ★★★
- "가장 효과적인 위험평가 방법은?"
- 답: 복합 접근법

---

### 2. 위험대응 전략 상세 ★★★

#### 위험 회피 (Risk Avoidance) ★★

**개념**:
```
위험한 활동이나 프로세스를 중단/포기
위험 자체를 제거
```

**적용 예**:
```
✓ 보안이 취약한 온라인 서비스 중단
✓ 해킹 위험 높은 시스템 폐기
✓ 위험 국가 진출 포기
✓ 클라우드 사용 중단
```

**장점**:
```
위험을 완전히 제거 (0%)
가장 확실한 방법
```

**단점**:
```
업무 제한/중단
기회 상실
비즈니스 영향
```

**실기 답안 작성**:
```
문제: "해킹 위험이 높은 온라인 서비스를 중단하는 전략은?"
답: "위험 회피 (Risk Avoidance)"
```

---

#### 위험 전가 (Risk Transfer) ★★★

**개념**:
```
위험을 제3자에게 이전
책임과 손실을 외부로 이전
```

**적용 예**:
```
✓ 보험 가입 (사이버 보험) ★★★
✓ 아웃소싱 (클라우드, IDC)
✓ 외주 개발 (보안 책임 이전)
✓ 계약서 명시 (면책 조항)
```

**장점**:
```
손실 부담 감소
전문성 활용
```

**단점**:
```
비용 발생 (보험료, 외주비)
완전한 책임 이전 불가능
법적 책임은 여전히 존재
```

**실기 답안 작성**:
```
문제: "화재 위험에 대비해 보험에 가입하는 전략은?"
답: "위험 전가 (Risk Transfer)"

문제: "클라우드로 서버를 이전하여 물리적 보안 책임을 이전하는 전략은?"
답: "위험 전가 (Risk Transfer)"
```

**2024년 출제**: ★★★
- 보험, 아웃소싱 예시 많이 출제

---

#### 위험 감소/완화 (Risk Mitigation) ★★★

**개념**:
```
보안대책을 구현하여 위험 수준 낮춤
가장 일반적이고 많이 사용하는 방법
```

**적용 예**:
```
기술적 보안대책:
✓ 방화벽 설치 ★★★
✓ 백신 설치
✓ 암호화 적용
✓ IDS/IPS 도입
✓ Prepared Statement (SQL Injection 방어)
✓ 패치 적용

관리적 보안대책:
✓ 보안 정책 수립
✓ 접근통제 강화
✓ 보안 교육
✓ 백업 수행

물리적 보안대책:
✓ 출입통제 시스템
✓ CCTV 설치
✓ 이중화
```

**장점**:
```
업무 지속 가능
비용 대비 효과 우수
다양한 선택지
```

**단점**:
```
위험을 0으로 만들 수 없음
잔여위험 존재
지속적 관리 필요
```

**실기 답안 작성**:
```
문제: "SQL Injection 방어를 위해 Prepared Statement를 적용하는 전략은?"
답: "위험 감소/완화 (Risk Mitigation)"

문제: "방화벽을 설치하여 외부 공격을 차단하는 전략은?"
답: "위험 감소/완화 (Risk Mitigation)"
```

**2024년 출제**: ★★★
- 가장 많이 출제되는 전략
- 구체적인 보안대책 예시와 함께 출제

---

#### 위험 수용 (Risk Acceptance) ★★

**개념**:
```
일정 수준 이하의 위험을 그대로 수용
보안대책 비용 > 예상 손실 시 선택
```

**적용 조건**:
```
✓ 위험도가 낮음 (Low Risk)
✓ 대응 비용이 손실보다 큼
✓ 다른 전략 적용 불가능
✓ 경영진 승인 필요 ★★
```

**적용 예**:
```
✓ 낮은 수준의 보안 위협
✓ 발생 가능성 극히 낮은 위험
✓ 잔여위험 (Residual Risk) ★★★
```

**장점**:
```
비용 절감
업무 영향 없음
```

**단점**:
```
위험 발생 시 전액 손실
정기적 재평가 필요
```

**실기 답안 작성**:
```
문제: "위험도가 낮아 별도 조치 없이 그대로 두기로 한 전략은?"
답: "위험 수용 (Risk Acceptance)"

문제: "보안대책 적용 후 남은 위험을 수용하는 전략은?"
답: "위험 수용 (Risk Acceptance) - 잔여위험"
```

**2024년 출제**: ★★
- 잔여위험과 함께 출제되는 경향

---

### 3. 자산, 위협, 취약점 상세 ★★★

#### 자산 (Asset) ★★★

**정의**:
```
조직이 보호해야 할 가치 있는 대상
```

**분류**:
```
1. 정보자산 ★★★
   - 데이터베이스 (고객정보, 거래정보)
   - 소스코드
   - 문서 (설계서, 매뉴얼)
   - 백업 데이터

2. 물리적 자산 ★★
   - 서버, PC, 네트워크 장비
   - 저장매체 (HDD, USB)
   - 건물, 전산실

3. 인적 자산 ★★
   - 임직원
   - 보안 담당자
   - 외주 인력

4. 무형 자산 ★
   - 기업 평판
   - 브랜드 가치
   - 지적재산권
```

**자산가치 평가 기준 (CIA)**: ★★★
```
C (기밀성): 유출 시 영향
I (무결성): 위변조 시 영향
A (가용성): 중단 시 영향

평가 척도:
5 - 치명적 (Critical)
4 - 높음 (High)
3 - 보통 (Medium)
2 - 낮음 (Low)
1 - 경미 (Minimal)
```

**실기 출제 예**:
```
문제: "자산을 3가지 유형으로 분류하시오"
답: "정보자산, 물리적 자산, 인적 자산"
```

---

#### 위협 (Threat) ★★★

**정의**:
```
자산에 손실을 입힐 수 있는 잠재적 요인
```

**분류**:
```
1. 자연적 위협 (Natural Threat) ★★
   - 지진, 홍수, 태풍
   - 화재, 낙뢰
   - 생물학적 재해

2. 인적 위협 (Human Threat) ★★★
   내부자 위협:
   - 고의적: 정보 유출, 시스템 파괴
   - 비고의적: 실수, 오조작

   외부자 위협:
   - 해킹, 악성코드
   - 사회공학 공격
   - DDoS 공격

3. 환경적 위협 (Environmental Threat) ★★
   - 정전, 전력 불안정
   - 온습도 이상
   - 통신 장애
   - 먼지, 오염
```

**위협 발생 가능성 평가**: ★★
```
5 - 매우 높음 (거의 확실)
4 - 높음 (자주 발생)
3 - 보통 (가끔 발생)
2 - 낮음 (드물게 발생)
1 - 매우 낮음 (거의 없음)
```

**실기 출제 예**:
```
문제: "위협을 3가지 유형으로 분류하고 각 예를 드시오"
답:
"1. 자연적 위협: 지진, 화재
 2. 인적 위협: 해킹, 내부자 공격
 3. 환경적 위협: 정전, 통신 장애"
```

**2024년 출제**: ★★★
- 내부자 위협 vs 외부자 위협 비교 문제

---

#### 취약점 (Vulnerability) ★★★

**정의**:
```
위협이 악용할 수 있는 자산의 약점
```

**분류**:
```
1. 기술적 취약점 ★★★
   - 패치 미적용 (보안 업데이트 누락)
   - 설정 오류 (디렉토리 인덱싱, 불필요한 서비스)
   - 약한 암호화 (MD5, DES 사용)
   - SQL Injection, XSS 등 코딩 결함

2. 관리적 취약점 ★★
   - 보안 정책 부재
   - 보안 교육 미흡
   - 접근통제 미흡
   - 로그 관리 부실

3. 물리적 취약점 ★★
   - 출입통제 미비
   - CCTV 부재
   - 이중화 미구성
   - 소화설비 부족
```

**취약점 심각도 평가**: ★★
```
CVSS (Common Vulnerability Scoring System)
- Critical: 9.0~10.0
- High: 7.0~8.9
- Medium: 4.0~6.9
- Low: 0.1~3.9
```

**실기 출제 예**:
```
문제: "취약점을 3가지 유형으로 분류하시오"
답: "기술적 취약점, 관리적 취약점, 물리적 취약점"

문제: "패치 미적용은 어떤 유형의 취약점인가?"
답: "기술적 취약점"
```

**2024년 출제**: ★★★
- CVSS 점수 기반 우선순위 문제

---

### 4. 위험평가 실무 ★★★

#### 위험도 계산 실습 ★★★

**예제 1**: 고객정보 DB
```
자산가치:
- 기밀성: 5 (매우 중요, 유출 시 치명적)
- 무결성: 4 (높음, 위변조 시 업무 마비)
- 가용성: 5 (매우 중요, 중단 불가)
- 평균: (5+4+5)/3 = 4.67 → 5

위협:
- 해킹: 4 (높음, 자주 발생)
- 내부자 유출: 3 (보통)
- 선택: 4

취약점:
- 패치 미적용: 4 (높음)
- 접근통제 미흡: 3 (보통)
- 선택: 4

위험도 = 5 × 4 × 4 = 80 (매우 높음) ★★★
```

**예제 2**: 일반 사무 PC
```
자산가치: 2 (낮음)
위협: 2 (악성코드, 드물게)
취약점: 3 (백신 미설치)

위험도 = 2 × 2 × 3 = 12 (낮음)
```

**위험도 등급 분류**:
```
80 이상: 매우 높음 (Critical) → 즉시 조치 ★★★
60~79: 높음 (High) → 1개월 이내 조치
40~59: 보통 (Medium) → 3개월 이내 조치
20~39: 낮음 (Low) → 6개월 이내 검토
19 이하: 매우 낮음 (Minimal) → 수용
```

---

#### 보안대책 수립 ★★★

**위험도 80 (고객정보 DB) 대응**:
```
위험 감소 전략 선택:

1. 기술적 대책
   ✓ 패치 즉시 적용 (취약점 4→1)
   ✓ DB 암호화 (AES-256)
   ✓ DB 방화벽 설치
   ✓ 침입탐지 시스템 (IDS)

2. 관리적 대책
   ✓ 접근권한 최소화 (Need-to-Know)
   ✓ 특권 계정 관리 강화
   ✓ 로그 모니터링 (실시간)

3. 물리적 대책
   ✓ DB 서버 통제구역 배치
   ✓ 이중 인증 출입통제

결과:
취약점 4 → 2 (대책 적용)
위험도 = 5 × 4 × 2 = 40 (보통)
잔여위험 40 수용 (경영진 승인)
```

## 💡 실전 암기 팁

### 핵심 공식 ★★★

```
위험도 = 자산가치 × 위협 × 취약점

잔여위험 = 초기위험 - 보안대책
```

### 위험대응 4가지 암기법 ★★★

```
"회전감수" 로 암기!

회 - 회피 (Avoid)
전 - 전가 (Transfer)
감 - 감소 (Mitigate)
수 - 수용 (Accept)
```

### 방법론 비교표 암기 ★★★

```
베이스라인: 빠르고 간편, 특성 반영 X
비정형: 유연하지만 일관성 X
상세분석: 정확하지만 시간/비용 多
복합: 가장 효과적 (정답으로 많이 출제!)
```

### CIA 암기 ★★★

```
C - Confidentiality - 기밀성 - 암호화
I - Integrity - 무결성 - 해시/전자서명
A - Availability - 가용성 - 백업/이중화
```

## 🔥 2024년 출제 경향

### 최빈출 주제 ★★★

1. **위험도 계산**
   - 자산×위협×취약점 공식 계산 문제
   - 실제 숫자 대입하여 계산

2. **위험대응 전략**
   - 상황 제시 후 적절한 전략 선택
   - 보험→전가, 방화벽→감소 패턴

3. **상세 위험분석 4단계**
   - 자산→위협→취약점→위험도 순서

4. **CIA Triad**
   - 정의 및 예시
   - 자산가치 평가 기준

5. **복합 접근법**
   - "가장 효과적인 방법은?" → 복합 접근법

### 실기 답안 작성 팁

```
1. 위험도 계산은 공식 명시 후 계산
   예: 위험도 = 5 × 4 × 3 = 60

2. 위험대응 전략은 영문 병기
   예: 위험 전가 (Risk Transfer)

3. 절차는 번호 매겨 순서대로
   예: 1. 자산 식별 2. 위협 식별...

4. CIA는 풀어서 설명
   예: C (Confidentiality, 기밀성)

5. 구체적인 예시 추가하면 가산점
   예: 전가 전략 - 사이버 보험 가입, 클라우드 아웃소싱
```
