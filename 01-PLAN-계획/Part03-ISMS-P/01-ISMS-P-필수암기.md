### 문제 4. CCTV 안내판 필수 항목 ★★★

**문제**: 개인정보보호법에 따른 CCTV 설치 시 안내판에 반드시 포함되어야 하는 3가지 정보를 쓰시오.

**✅ 정답**:
```
1. 설치 목적 및 장소

```

**상세 설명**:

- 안내판은 설치 목적지 인근 잘 보이는 곳에 부착
- 2024년 실기 출제 ★★★

### 문제 5. 직무분리 원칙 ★★

**문제**: 정보보호 관리체계에서 직무분리(Separation of Duties)를 해야 하는 이유를 서술하시오.

**✅ 정답**:
```
한 사람이 중요한 업무의 전 과정을 처리하지 못하도록 하여,
내부자에 의한 부정행위나 오류를 방지하기 위함
```

**상세 설명**:
- 인적 보안의 핵심 원칙
- 예시:
  - 시스템 개발자 ≠ 운영자
  - 결제 승인자 ≠ 실행자
  - 감사 대상자 ≠ 감사자
- 견제와 균형 (Check and Balance) 원리
- 2023년 실기 출제 ★★

---

### 문제 6. Clear Desk/Clear Screen 정책 ★★★

**문제**: Clear Desk 정책과 Clear Screen 정책의 내용을 각각 설명하시오.

**✅ 정답**:
```
Clear Desk: 업무 종료 시 책상 위의 중요 문서나 저장매체를
           잠금장치가 있는 곳에 보관하는 정책

Clear Screen: 업무 이탈 시 화면 잠금(Screen Lock)을 설정하여
             화면에 표시된 정보가 노출되지 않도록 하는 정책
```

**상세 설명**:
- 물리적 보안의 기본 통제
- Windows: Win + L (화면 잠금)
- Linux: Ctrl + Alt + L
- 자동 화면 잠금 설정 권장 (5~10분)
- 2024년 실기 출제 ★★★

---

### 문제 7. 퇴직자 보안 조치 ★★

**문제**: 직원 퇴직 시 반드시 수행해야 하는 보안 조치 3가지를 쓰시오.

**✅ 정답**:
```
1. 계정 삭제 또는 비활성화
2. 자산(노트북, 출입카드 등) 반납
3. 보안 서약 연장 (비밀유지서약)
```

**상세 설명**:
- 퇴직 당일 즉시 계정 삭제
- VPN, 원격접속 권한 즉시 회수
- 재직 중 접근한 정보에 대한 비밀유지 의무 연장
- 2023년 실기 출제 ★★

## 🔴 보호대책 요구사항 (64개 항목)

### 1. 정책/조직/자산 관리 ★★

**정책 수립 및 유지관리**
```
정보보호 정책
- 승인 및 공표
- 주기적 검토 (연 1회 이상)
- 변경 관리
```

**자산 분류 및 관리**
```
자산 식별 → 분류 → 등록 → 관리
중요도: 상/중/하
```

### 2. 인적 보안 ★★★

**보안 서약서** (입사 시)
```
- 비밀유지 의무
- 정보보안 준수 사항
- 위반 시 제재
```

**보안 교육** (연 1회 이상) ★★★
```
- 정보보호 인식 제고
- 개인정보보호 교육
- 신규 입사자 교육
```

**직무 분리** (Separation of Duties) ★★
```
개발 ≠ 운영
승인 ≠ 실행
감사 대상 ≠ 감사자
```

### 3. 외부자 보안 ★★

**외주 개발 보안**
```
- 보안 요구사항 명시
- 소스코드 보안점검
- 인수인계 절차
```

**클라우드 보안**
```
- 데이터 위치 파악
- SLA 계약 명시
- 데이터 반환 절차
```

### 4. 물리적 보안 ★★★

**출입통제**
```
보안구역 분류:
1. 통제구역 (핵심 자산) - 이중 인증 ★★★
2. 제한구역 (중요 자산) - 출입기록
3. 개방구역 (일반 업무)
```

**CCTV 운영** ★★★
```
설치 시 안내판:
1. 설치 목적 및 장소
2. 촬영 범위 및 시간
3. 관리책임자 연락처
```

### 5. 인증 및 권한 관리 ★★★

**사용자 계정 관리**
```
- 고유 식별자 부여
- 불필요한 계정 삭제
- 공용 계정 사용 금지 ★★
```

**패스워드 정책** ★★★
```
복잡도:
- 길이: 최소 10자 이상
- 조합: 영문대소문자+숫자+특수문자

변경 주기:
- 일반: 90일 이내 ★★★
- 특권: 60일 이내

기타:
- 이전 패스워드 재사용 제한 (최근 5개)
- 초기 패스워드 즉시 변경
```

**특권 계정 관리** ★★★
```
root, Administrator, sa 등
- 별도 관리
- 사용 시 승인
- 로그 기록 ★★★
```

### 6. 접근통제 ★★★

**네트워크 접근통제**
```
- 방화벽 정책 관리
- ACL 설정
- NAC (Network Access Control) ★★
```

**최소 권한 원칙** (Least Privilege) ★★★
```
업무 수행에 필요한 최소한의 권한만 부여
Need-to-Know 원칙
```

### 7. 암호화 ★★★

**암호 알고리즘**
```
국가정보원 검증 암호:
- ARIA, SEED, LEA, HIGHT (대칭키) ★★★
- ECDSA (비대칭키)
- LSH (해시)

또는 다음 국제 표준:
- AES, RSA, SHA-256 이상 ★★★
```

**암호키 관리**
```
- 키 생성: 안전한 난수생성기 사용
- 키 저장: 암호화하여 보관
- 키 폐기: 안전한 삭제 (DoD 5220.22-M)
- 키 변경: 주기적 (연 1회 이상)
```

### 8. 정보시스템 도입 및 개발 보안 ★★

**보안 요구사항 정의**
```
개발 초기 단계부터 보안 고려
Security by Design
```

**시큐어 코딩** ★★★
```
OWASP Top 10 대응:
1. SQL Injection → Prepared Statement ★★★
2. XSS → 입력값 검증/출력값 인코딩
3. CSRF → Token, SameSite Cookie
```

### 9. 시스템 및 서비스 운영관리 ★★

**변경 관리**
```
변경 요청 → 검토 → 승인 → 구현 → 검증
롤백 계획 수립 필수
```

**백업 관리** ★★★
```
주기:
- 전체 백업: 주 1회
- 증분 백업: 일 1회

보관:
- 원본과 다른 장소
- 암호화 보관 ★★★
```

### 10. 시스템 및 서비스 보안관리 ★★★

**취약점 점검** ★★★
```
주기:
- 서버: 분기 1회 이상
- PC: 반기 1회 이상
- 신규 도입 시: 즉시

도구:

```

**악성코드 방지** ★★★
```
백신:
- 최신 엔진 유지 (일 1회 업데이트)

```

### 11. 사고 예방 및 대응 ★★★
