# 보안 솔루션 - 필수 암기

## 🔴 CAPTCHA ★★★

### 문제 (2024년 기출)
```
CAPTCHA에 대한 설명으로 올바른 것은?
```

### ✅ 정답
```
CAPTCHA (Completely Automated Public Turing test to tell Computers and Humans Apart)
= 컴퓨터와 인간을 구별하기 위한 완전 자동화된 공개 튜링 테스트

정의:
사람인지 봇(자동화 프로그램)인지 구별하는 인증 기술

목적:
- 자동화된 봇 공격 방어
- 무차별 대입 공격 방지 (Brute Force)
- 스팸 등록/댓글 차단

종류:
1. 텍스트 기반
   - 왜곡된 문자/숫자 입력
   - 가장 기본적

2. 이미지 기반
   - "신호등이 있는 이미지 선택"
   - reCAPTCHA v2

3. 체크박스
   - "저는 로봇이 아닙니다" 클릭
   - reCAPTCHA v2 Invisible

4. 행동 분석 기반
   - 마우스 움직임, 클릭 패턴 분석
   - reCAPTCHA v3 (점수 기반)

단점:
- 사용자 불편
- 접근성 문제 (시각 장애인)
- AI/ML로 우회 가능성
```

## 🔴 허니팟 / 허니넷 ★★

### 문제 (2024년 기출)
```
공격자를 유인하는 보안시스템?
```

### ✅ 정답
```
허니팟 (Honeypot) ★★★
또는
허니넷 (Honeynet)

정의:
의도적으로 취약점을 가진 시스템을 구축하여
공격자를 유인하고 공격 패턴을 분석하는 미끼 시스템

목적:
1. 공격 패턴 분석
2. 공격자 추적
3. 실제 시스템 보호 (주의 분산)
4. 위협 인텔리전스 수집

종류:
1. 허니팟 (Honeypot)
   - 단일 시스템
   - 특정 서비스 에뮬레이션 (FTP, SSH, 웹 등)

2. 허니넷 (Honeynet)
   - 여러 허니팟으로 구성된 네트워크
   - 실제 네트워크처럼 구성

레벨:
- Low-interaction: 제한된 서비스만 제공 (안전)
- High-interaction: 실제 시스템 (위험하지만 정보 많음)

주의사항:
허니팟 자체가 공격 기반으로 악용될 위험
격리된 네트워크에 구축 필요
```

## 🔴 수리카타 (Suricata) ★★

### 문제 (2024년 기출)
```
수리카타의 특징은?
```

### ✅ 정답
```
Suricata

정의:
오픈소스 IDS/IPS (침입 탐지/방지 시스템)
Snort의 대안

주요 특징:

1. 멀티스레딩 ★★★
   - 다중 CPU 코어 활용
   - Snort보다 빠름 (Snort는 단일 스레드)

2. 통합 IDS/IPS/NSM
   - IDS: 침입 탐지
   - IPS: 침입 방지
   - NSM: 네트워크 보안 모니터링

3. 프로토콜 지원
   - HTTP, TLS, SMB, FTP 등 프로토콜 파싱
   - 파일 추출 및 분석

4. Snort 룰 호환
   - Snort 룰 그대로 사용 가능

5. JSON 출력
   - EVE (Extensible Event Format)
   - ELK Stack 연동 용이

Snort vs Suricata:
┌──────────┬──────────┬──────────┐
│   구분   │  Snort   │ Suricata │
├──────────┼──────────┼──────────┤
│ 스레딩   │ 단일     │ 멀티 ★  │
│ 성능     │ 보통     │ 높음     │
│ 프로토콜 │ 기본     │ 고급     │
│ 출력     │ 다양     │ JSON     │
└──────────┴──────────┴──────────┘
```

## 🔴 취약점 분석 도구 ★★

### 문제 (2024년 기출)
```
취약점 분석도구로 올바른 것은?
```

### ✅ 정답
```
주요 취약점 스캐너:

1. Nessus ★★★ (상용)
   - 가장 유명
   - 플러그인 기반
   - 수만 개 취약점 DB

2. OpenVAS (오픈소스)
   - Nessus 오픈소스 버전
   - 무료

3. Qualys (클라우드 기반)
   - SaaS 형태
   - 에이전트 또는 스캐너

4. Nikto (웹 전용)
   - 웹 서버 취약점 스캔
   - 오픈소스

5. OWASP ZAP (웹 전용)
   - 웹 애플리케이션 취약점
   - 오픈소스

6. Acunetix (웹 전용, 상용)
   - SQL Injection, XSS 등

7. Burp Suite (웹 전용)
   - 침투 테스트 도구
   - Professional (상용), Community (무료)

실기 답안:
Nessus, OpenVAS, Nikto, OWASP ZAP 등
```

## 🔴 Kali Linux 도구 ★

### 문제 (2024년 기출)
```
Kali 리눅스에서 사용하지 않는 도구는?

ㄱ. Nmap
ㄴ. Metasploit
ㄷ. Wireshark
ㄹ. MS Office
```

### ✅ 정답
```
ㄹ. MS Office ★

Kali Linux 주요 도구:

정보 수집:
- Nmap (포트 스캔)
- Netdiscover (네트워크 탐색)
- Maltego (정보 수집)

취약점 분석:
- OpenVAS
- Nikto (웹)
- SQLmap (SQL Injection)

악용 (Exploitation):
- Metasploit Framework ★★★
- Armitage (Metasploit GUI)

스니핑:
- Wireshark
- tcpdump
- Ettercap

무선 공격:
- Aircrack-ng (Wi-Fi)
- Reaver (WPS)

패스워드 공격:
- John the Ripper
- Hydra
- Hashcat

웹 애플리케이션:
- Burp Suite
- OWASP ZAP
- Nikto

포렌식:
- Autopsy
- Volatility (메모리)

MS Office는 일반 오피스 소프트웨어로
Kali Linux에 포함되지 않음
```

## 🔴 DLP (Data Loss Prevention) ★★ (기출 재확인)

```
정의: 데이터 유출 방지 시스템

유형:
1. 네트워크 DLP
   - 이메일, 메신저 등 네트워크 전송 감시

2. 엔드포인트 DLP ★
   - PC에 에이전트 설치
   - USB, 프린터 등 통제

3. 저장소 DLP
   - DB, 파일 서버 민감 정보 탐지

기능:
- 민감 정보 자동 탐지 (주민번호, 신용카드 등)
- 차단 또는 암호화
- 로그 및 경고
```
